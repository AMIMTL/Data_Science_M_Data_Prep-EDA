# Data Science in Python: Data Prep & EDA

**Course source:** [Maven Analytics - Data Science in Python: Data Prep & EDA](https://mavenanalytics.io/course/data-science-in-python-data-prep-eda)

**Instructor:** Maven Analytics  
**Status:** ✅ Completed

## Course Overview
This hands-on, project-based course covers the core building blocks of Python for data science. Through a customer churn case study at Maven Music (a streaming service), you'll learn data preparation and exploratory data analysis (EDA) techniques.

## What You'll Learn

### Foundations
- Introduction to data science and machine learning
- Supervised vs. unsupervised learning
- The data science workflow

### Data Preparation
- Scoping a data science project
- Gathering data from multiple sources with Pandas
- Handling common data cleaning issues (missing values, duplicates, inconsistencies)

### Exploratory Data Analysis (EDA)
- Filtering and grouping data
- Data visualization techniques
- Providing actionable insights from customer data

### Preparing Data for ML Models
- Joining multiple tables
- Adjusting row granularity
- Feature engineering (creating useful fields and features)

## Course Project: Customer Churn Analysis
You'll play the role of a Jr. Data Scientist for Maven Music, a streaming service struggling with customer churn. Using Python, you will:
- Gather, clean, and explore customer data
- Provide insights about customers
- Prepare data for future machine learning models

## Prerequisites
- Basic Python knowledge (helpful but not required)
- Interest in data science and machine learning

## Repository Contents
- `/notebooks` - Jupyter notebooks for data prep and EDA techniques
- `/data` - Maven Music customer churn dataset
- `/projects` - Customer churn analysis project
- `/scripts` - Python scripts for data cleaning and exploration

- pandas (data manipulation and cleaning)
